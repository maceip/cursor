# Third-party implementation references

This prototype adapts design and implementation patterns from the archived Android references in `.shape/design/android-reference-apps/`.

- `prompt-bar-main.zip`: PromptBar, Apache License 2.0. Used as a reference for the headless composer state model, attachment chips, send-state handling, and trigger detection concepts. Local code is restyled for the Cursor/Claude design system.
- `Backtalk-master.zip`: Backtalk, MIT License. Used as a reference for mobile chat/input ergonomics, voice/send affordances, and rounded message surface behavior. Local code is restyled for the Cursor/Claude design system.
